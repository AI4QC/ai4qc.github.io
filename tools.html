🛠️ Tools & Open-Source Software

We believe in delivering useful, not just fancy tools. Everything below is developed or actively maintained by the AI4PhysSci Lab and released openly, following the modular Simulator → Emulator → Sampler → Predictor → Evaluator & Agent pipeline.

🔗 Full code base: github.com/AI4QC. Issues, pull requests, and collaborations are all welcome — see Openings if you would like to build these with us.

CatDT-GS

🤖 Agent

A self-evolving multi-agent system (digital twin) for autonomous heterogeneous catalysis discovery.

PRIS

🔎 Evaluator/🤖 Agent

Plausibility Rules for Inorganic Structures: eight one-line laws, found by autonomous agents that proposed, tested and refuted two million candidates, that judge whether a crystal structure is physicochemically plausible and name the mechanism that fails. Cheap enough to screen a generator's output before any DFT.

Python Released · arXiv:2609.01209 GitHub ↗ Project page ↗ Paper ↗

MateriaViva

🔮 Predictor

MateriaViva links 55 databases by structure into one resource of 14.6 million crystals and 131.8 million source-traced property values. Only 4.5% of the property matrix is filled; CGTNet supplies the rest as predictions kept apart from measurements. Use it to see how much performance is hidden in known crystals, and how new a generated crystal really is.

Python Released · arXiv:2610.32678 GitHub ↗ Project page ↗ Paper ↗
